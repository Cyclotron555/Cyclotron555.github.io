RED BLACK POKER

Data deletion

Updated October 24, 2026

Red Black Poker’s current HTML5 edition stores progress and settings in the browser’s local storage. It does not maintain a separate Tired Software account or cloud save service.

Delete a browser game’s saved progress

  1. Open the browser settings for site data or stored website data.
  2. Find the website where you played the game and clear its stored data. This resets the game’s local credits, wallet, statistics, saved hand, bonus meter, and settings.
  3. Reload the game. It will begin with fresh local progress.

Clearing stored data cannot be undone through the game and may clear other saved information for the selected website.

Facebook Instant Games

Facebook may host the game within a separate embedded game origin. Use the browser’s site-data controls to remove the stored data for that game origin. Facebook account information and activity are controlled by Meta and are separate from the game’s local save.

To review connected apps, open Facebook settings and look for Apps and websites or the relevant gaming controls. Removing an app connection and clearing local browser data are separate actions. Use Meta’s account controls for information Meta holds. See Meta’s privacy policy.

Need help?

Email tiredsoftware@gmail.com for help. Public projects are also available on the GitHub profile. Do not share passwords or identity documents. Since this version has no developer-operated account database, there is no Tired Software cloud account to delete.
