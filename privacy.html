PLAYER & WEBSITE INFORMATION

Privacy

Effective October 24, 2026

Tired Software is the independent development label of Claude Butnaru. This page describes this website and the current HTML5 edition of Red Black Poker.

This website

This site does not include an account system, contact form, advertising, or analytics scripts. It is intended for hosting on GitHub Pages. GitHub may process technical information associated with hosting and security, such as visitor IP addresses. See GitHub’s privacy statement for details.

Red Black Poker

The current game saves play credits, wallet balance, the current hand, held-card choices, pending winnings, bonus progress, settings, and game statistics in the browser’s local storage. These are simulated game values with no cash value. This edition does not include purchases, real-money wagering, or cash redemption.

The game does not run a Tired Software account service or transmit saved progress to a Tired Software server. Saved progress is not synchronized between devices. The current game does not request the player’s name, profile photo, email address, or friends list through its own code.

Playing through Facebook

The Facebook edition loads Meta’s Instant Games SDK to initialize the platform, report loading progress, start the game, and handle pauses. Meta processes information under its own policies and may associate game activity with your Facebook account. See Meta’s privacy policy and your Facebook privacy controls.

The current game code does not integrate in-game advertising or payments. Changes to those features would require updates to this information.

Retention and deletion

Local game progress remains until it is replaced, the browser or platform removes it, or you clear the game’s stored data. Read the data deletion instructions. Information held by GitHub or Meta is subject to their own retention practices and controls.

Daily Tarot Oracle

That app has a separate policy covering its local daily draw and third-party advertising services. Read the Daily Tarot Oracle privacy policy.
